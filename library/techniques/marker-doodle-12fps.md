# Marker Doodle 12fps
- **شو:** دوائر وأسهم ماركر بتنرسم فوق الصور، بفريمات أقل (12fps) من الفيديو.
- **ليش:** إحساس "إيد بشرية" بيكسر النظافة الرقمية (ضد علامات AI).
- **دليل:** OBSERVED (Gemini + r07 ~42s). التوقيت 0.38–0.42s للرسمة.
- **بالكيت:** `K.markerCircle / K.markerArrow` (خاصية `posterize: 12` بالمحرك).
