# سَنا — رحلة النور لتعلّم التجويد

نسخة عامة من اللعبة لأي طفل، بمحتوى كتاب «هَدْيُ الرحمن في مبادئ تجويد القرآن».

- كل لاعب يكتب اسمه ويختار شخصيته (أولاد / بنات)، وتُحفظ رحلته على الجهاز.
- عند العودة يضغط على بطاقته ويكمل من حيث توقف.
- الخطاب يتغيّر تلقائيًا للولد أو البنت.
- لوحة متابعة للأهل والمعلمين، وتحدّي الأصدقاء بين لاعبَين.
