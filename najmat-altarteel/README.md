# نجمات الترتيل

لعبة تعليمية لهدى وسنا لتعلّم أحكام التجويد، مبنية على كتاب «هَدْيُ الرحمن في مبادئ تجويد القرآن».

افتحي الملف `index.html` في أي متصفح (يعمل على الجوال والتابلت والكمبيوتر).

- ١٥ محطة (فانوس) تتبع ترتيب الكتاب: الآداب، الاستعاذة والبسملة، الغنة، أحكام النون الساكنة والتنوين، الميم الساكنة، القلقلة، أنواع الإدغام، الراء، المدود.
- كل محطة: شرح مصوّر ثم ٢-٣ ألعاب (أسئلة، سلال الفرز، فقاعات الحروف، بطاقات الذاكرة، ترتيب الكلمات، صح أم خطأ، ميزان المد).
- ساحة الألعاب بثلاثة مستويات، وتحدّي الأختين (هدى ضد سنا)، وشارات، وشهادة في النهاية.
- التقدّم يُحفظ لكل بنت على الجهاز نفسه.
