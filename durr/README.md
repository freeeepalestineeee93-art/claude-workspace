# الدر الثمين — منصّة تفاعلية لتعلّم التجويد

منصّة ويب لتعلّم التجويد بالألعاب والاختبارات، مبنيّة على كتاب **«الدر الثمين في تجويد كلام رب العالمين»** لمحمد حمزة عطار وأحمد خلوف أديب (مؤسسة إتقان للتعليم والتنمية). كل المحتوى مأخوذ من الكتاب نفسه، وبجانب كل شرح رقمُ صفحته فيه.

## ماذا تضم المنصّة

- **الرحلة**: ١٠ وحدات فيها ٤٤ درساً قصيراً تغطي الكتاب كاملاً (من آداب التلاوة إلى التفخيم والترقيق). تعرض الدروس التعريفات والجداول وأبيات الجزرية والتنبيهات وتعليل الأمثلة، مع مخططات تفاعلية.
- **اختبار لكل وحدة**: بنك من ٢٠٥ أسئلة، فيه شرح فوري لكل إجابة مع رقم الصفحة. إذا اجتزت الاختبار بنسبة ٧٠٪ تُضاف «دُرّة» إلى عقدك.
- **ساحة التحدّي**: ٨ ألعاب هي: مصنّف أحكام النون، ومصنّف الميم الساكنة، وشمسيّة أم قمريّة، وميزان المدّ، وصواب أم خطأ، وأكمل الشاهد، واستخرج الصفات، واصطد المخرج.
- **بطاقات المراجعة**: ٥٢ بطاقة تعمل بطريقة التكرار المتباعد (صناديق لايتنر).
- **دفتر الأخطاء** و**تحدّي اليوم** و**الامتحان الشامل**.
- **مختبر الحروف**: المخرج والصفات واللقب لكل حرف، ومخطط تفاعلي للفم والحلق، ومخطط للأسنان.
- **التحفيز**: درر، ورتب، وأيام متتالية، و١٤ وساماً. يُحفظ التقدّم في متصفّح المستخدم.

## التشغيل

افتح `index.html` في المتصفح، أو افتح النسخة المجمّعة في ملف واحد `dist/durr.html` (تعمل دون خادم).

بعد أي تعديل في الملفات أعد بناء النسخة المجمّعة:

```
python3 build.py
```

## بنية الملفات

| الملف | المحتوى |
|---|---|
| `js/data-lessons.js` | الوحدات والدروس |

| `js/app.js` | منطق التطبيق: الواجهة والألعاب والحفظ |
| `css/style.css` | التصميم (فاتح وداكن، ومتجاوب مع الجوال) |
