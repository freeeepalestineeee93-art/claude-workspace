# حلقة النقد

```bash
node studio.mjs critique projects/<p>/videos/<v>/main.js
```
بيطلع `renders/critique/sheet.png` + `report.md` + `report.json`.

## خطوات كل جولة
1. **اقرأ التقرير:** المشاكل "مهم" (تراكب، تباين، hook) لازم تنصلح أولاً.
2. **افتح sheet.png** وقيّم من 10 بصراحة:
   | المحور | سؤال |
   |---|---|
   | التكوين | في نقطة تركيز وحدة؟ في فراغ مقصود؟ مش كل شي بالنص؟ |
   | التايبوغرافي | تباين أحجام قوي؟ الخط العربي سليم؟ ما في نص طويل؟ |
   | الإيقاع | قصير-قصير-طويل؟ هدوء قبل الذروة؟ شريط الطاقة متنوع؟ |
   | الحركة | وزن مناسب؟ overlapping؟ خروج لكل عنصر؟ |
   | الهوية | الألوان والخطوط من brand.json؟ |
   | Hook | أول 0.5s فيها حركة/سؤال؟ |
   | النهاية | لحظة ختام واضحة؟ |
3. افحص قائمة `docs/craft/ai-tells.md`.
4. اكتب **أسوأ 3 مشاكل** بجملة وحدة لكل منها، وصلّحهم بالكود.
5. لحظة محددة مشكوك فيها؟ `node studio.mjs render <main.js> --still 2.4` وافتح الصورة.
6. كرر. **التوقف:** كل محور ≥ 8 + ما في "مهم" بالتقرير. (عادة 3–5 جولات.)

احفظ ملخص كل جولة بـ `videos/<v>/critique-log.md` (الجولة، التقييمات، شو انصلح) — بيفيد المستخدم يشوف التطور.
