# Script analysis (full script)

Read the whole script before answering. Reply in Arabic, compact, in this order:

1. **الفيلم:** العنوان، جملة ملخّص (logline)، النبرة.
2. **المشاهد:** جدول واحد:

   | # | المشهد | الملخص | المكان | الشخصيات | مدة تقديرية | خطة الإخراج ونقطة القطع |
   |---|---|---|---|---|---|---|

   - اتبع تقسيم السكربت إذا موجود، وإلا قسّم حسب المكان والزمن والنبضة الدرامية.
   - المدة التقديرية من طول التعليق أو الحوار (العربي ≈ كلمتين بالثانية) + النبضات البصرية. المستخدم يحدد المدة النهائية لاحقاً.
3. **الشخصيات:** لكل شخصية: الاسم (+ تهجئة إنجليزية صوتية)، دورها، ملامحها بالإنجليزي (age, face, hair, build, costume, colors, era)، الأعمار إذا ظهرت بأكثر من عمر، والبصمة الصوتية إذا بتتكلم أو بتروي. والشخصيات اللي ما بتتكلم.
4. **الأغراض وحالتها:** حالة كل غرض مهم مشهداً بمشهد (سليم / متضرر / مُصلَح / مكانه)، وأي تمهيد بصري لازم بمشهد سابق.
5. **الأماكن:** وصف بصري مختصر بالإنجليزي لكل مكان.
6. **ثغرات وحلول:** كل ثغرة منطقية أو بصرية مع حلها.
7. **للمونتاج:** كل نص أو تاريخ أو إشارة مكان أو لافتة أو خريطة أو شاشة كتابة يطلبها السكربت، مع رقم المشهد. (هذه لا تُولَّد أبداً.)
8. **أفكار إبداعية للفيلم** (وضع المبدع فقط): ٣–٥ اتجاهات جريئة ومبرَّرة (موتيفات بصرية، انتقالات، وجهة نظر، تطوّر لوني)، مرقّمة، والمستخدم يقبل منها.
9. **٣ اتجاهات ستايل** إذا الهوية ما فيها ستايل: لكل اتجاه اسم عربي، سبب مناسبته بجملة، وفقرة STYLE كاملة بالإنجليزي داخل Code Block جاهزة للصق.

Keep the Arabic sections short. Precision over length.
