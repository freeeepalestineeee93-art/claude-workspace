# مبادئ الحرفة: كيف يفكّر سينيور موشن

هالملف هو "الذوق" المكتوب. اقرأه قبل أي فيديو، وارجع له بكل جولة نقد.

## ١. الهرمية قبل الحركة
- **شي واحد مهم بكل لحظة.** إذا كل العناصر عم تتحرك سوا، ولا شي مهم.
- رتّب كل مشهد: البطل (عنوان/رقم/منتج) ← الداعم (سطر شرح) ← الزينة (أشكال، جزيئات).
- البطل بياخد أقوى حركة وأكبر حجم وأعلى تباين. الزينة بتتحرك ببطء وبشفافية أقل.

## ٢. التوقيت: جداول جاهزة
| العنصر | المدة | الـ spring/ease |
|---|---|---|
| أيقونة، زر، نقطة | 0.25–0.4s | `snappy` |
| كرت، صندوق، صورة | 0.5–0.8s | `default` |
| عنوان كبير | 0.7–1.1s | `heavy` أو `glide` |
| لوغو | 1–1.6s | `heavy` + draw |
| خلفية، جو عام | 3–10s | `gentle` / wiggle بطيء |
| خروج | 60% من مدة الدخول | `cubicIn` / `expoIn` |

- **الدخول أبطأ من الخروج.** الخروج سريع وحاسم.
- **stagger بين الكلمات** 0.05–0.09s، وبين الحروف 0.02–0.04s، وبين الكروت 0.08–0.14s.
- **لا تخلّي الشاشة تتنفس أكتر من 1.2s بدون شي جديد** (إلا لحظة صمت مقصودة قبل ذروة).

## ٣. الوزن والفيزياء
- كل شي إله كتلة: الكبير بطيء الانطلاق وما بيرتد، الصغير سريع وممكن يرتد شوي.
- **Overlapping action:** لا توقف كل الأجزاء بنفس اللحظة. خلي الخلفية تكمل نص ثانية بعد ما يوقف البطل.
- **Anticipation:** قبل حركة قوية، رجوع صغير لورا (`ease: 'anticipate'` أو scale 1→0.96→1.1).
- **Follow-through:** بعد ما يوصل العنصر، اهتزاز صغير بعنصر تابع (ظل، خط تحت، جزيئات).
- استعمل `track()` (spring بأهداف متعددة) لما عنصر بيغيّر هدفه أكتر من مرة، بدل keyframes منفصلة.

## ٤. التكوين
- **ابعد عن النص بالنص دايماً.** جرّب: عنوان على الثلث، محاذاة يمين (طبيعي للعربي)، نص كبير بيطلع برا الإطار جزئياً.
- **تباين الأحجام** قوي: عنوان 160px جنب سطر 48px أحلى من 100 و80.
- **الفراغ مقصود:** 30–45% من الإطار فاضي بأغلب اللحظات.
- خلي في **طبقات عمق**: خلفية (z بعيد، ضبابية، بطيئة) ← وسط ← مقدمة (أحياناً عنصر قريب جداً بيعبر).
- **المناطق الآمنة** للريلز: ما في نص مهم بأعلى 11%، ولا بأسفل 20%، ولا بآخر 12% يمين.

## ٥. العربي: قواعد ما بتنكسر
- **ممنوع تقطيع الحروف بـ DOM أو CSS letter-spacing.** التحريك بالحرف بيمر عبر محرك HarfBuzz عندنا (`by: 'char'`) ليضل الوصل سليم.
- **الكشيدة هي letter-spacing العربي.** استعملها للتمدد والتأكيد، مرة وحدة بالكلمة، وبمكانها الصح (المحرك بيختاره تلقائياً).
- اتجاه الحركة: الدخول من **اليمين**، والـ stagger **من اليمين لليسار** (ترتيب القراءة). التظليل والخطوط بتمشي من اليمين.
- ارتفاع السطر للعربي أكبر: 1.3–1.5 (بسبب النقاط والحركات).
- **الأوزان:** العناوين 700–900، النص 400–500. لا تستعمل Thin بأحجام صغيرة.
- **أزواج خطوط مجرّبة:**
  - حديث وتقني: Noto Kufi Arabic (عناوين) + IBM Plex Sans Arabic (نص)
  - دافئ وإنساني: Alexandria + Readex Pro
  - تراثي/فاخر: Aref Ruqaa أو Amiri (لمسة) + Noto Naskh Arabic
  - جريء وإعلاني: Lalezar أو Rakkas (كلمة وحدة!) + Tajawal
  - مرح: Marhey أو Lemonada + Baloo Bhaijaan 2
  - تحريري: Markazi Text + IBM Plex Sans Arabic
- الأرقام: بالمحتوى العربي العام `digits: 'ar'` (٠١٢٣)، وبالتقني/المالي `'en'` حسب جمهورك.

## ٦. الإيقاع والمونتاج
- **أول ثانيتين = كل شي.** ابدأ بحركة أو سؤال أو رقم صادم، مش بلوغو.
- مفاجأة بصرية كل **3–5 ثواني** (انتقال، تغيير حجم، لون جديد، عنصر بيكسر النمط).
- نوّع أطوال المشاهد: **قصير-قصير-طويل**. ثلاث مشاهد متساوية = ملل.
- اقطع **على الـ beat** (`S.beat(n)`, `S.snap(t)`). الانتقالات القوية على أول beat بالـ bar.
- **لحظة هدوء قبل الذروة** (0.3–0.6s شبه ساكنة) بتضاعف أثر الذروة.

## ٧. الانتقالات: قاموس
| الانتقال | إمتى |
|---|---|
| `cut` على beat | الإيقاع السريع، الأكثر احترافية غالباً |
| `push` / `whip` | تتابع أفكار، "التالي" |
| `zoom` | دخول لتفصيل، أو كشف |
| `iris` / `shape` | كشف منتج/شاشة، فتح تطبيق |
| `dip` (لون الهوية) | فصل بين أقسام |
| `flash` | ذروة، إعلان |
| `glitch` | تقني، تحذير، "خطأ" |
| `gl:*` | لمسات خاصة، باعتدال (مرة بالفيديو) |
| **match cut** (يدوي) | الأفخم: شكل بيتحول لشكل بالمشهد الجاي (نفس المكان/اللون) |

لا تستعمل نفس الانتقال أكتر من مرتين متتاليتين.

## ٨. الملمس (ضد الإحساس الرقمي)
- **grain** خفيف دايماً (0.03–0.06).
- **motion blur** شغّال دايماً بالنهائي.
- vignette خفيف (0.25–0.4).
- bloom على العناصر المضيئة فقط (threshold عالي 0.7+).
- chromatic aberration ضئيل جداً (≤0.0015) أو بلاش.
- تدرجات الخلفية: radial ناعم بلون الهوية بشفافية 20–35%، وبيتحرك ببطء (wiggle).

## ٩. الصوت
- **كل حركة مهمة إلها صوت**، والصوت **بطول الحركة** (المحرك بيعمل هالشي تلقائياً).
- الـ whoosh **قمته** على لحظة أسرع حركة، مش على بدايتها.
- الذروات: impact + لحظة صمت قبلها.
- الموسيقى -8 لـ -6 dB تحت المؤثرات، وبتوطى تحت الكلام تلقائياً.
- النهاية: ضربة نهائية مع آخر فريم + ذيل صوتي (المولّد بيعملها).

## ١٠. النهاية
- لحظة ختام واضحة: لوغو بيترسم، أو دعوة لفعل (CTA)، أو سطر أخير قوي.
- خلي آخر 0.6–1s ثابتة نسبياً (المشاهد بيقرأ).
- للـ loop: آخر فريم = أول فريم.
